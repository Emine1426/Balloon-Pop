# 🎈 Balloon Pop

![Balloon Pop](./balon-patlatma.png)

A mobile arcade game developed with Unity where players pop balloons and try to achieve the highest score.

---

## 🎮 Features

- 🎈 Balloon popping gameplay
- 🏆 Score system
- 📱 Mobile-friendly controls
- 🎨 Colorful 2D graphics
- 🔊 Sound effects
- ⚡ Simple and fun gameplay

---

## 🛠️ Built With

- Unity
- C#
